# Loophole Themes

Official color themes for Loophole IDE.

## Themes Included

### Loophole Dark
A carefully crafted dark theme with a unique purple/iris accent (#c5a8e8) that creates a modern, comfortable coding environment perfect for long coding sessions.

**Color Palette:**
- **Base:** `#1a1825` - Deep purple-black background
- **Surface:** `#201e2f` - Editor background
- **Overlay:** `#27243b` - Widget backgrounds
- **Iris:** `#c5a8e8` - Primary accent (focus, highlights)
- **Love:** `#ec7093` - Keywords, errors
- **Gold:** `#f7c278` - Strings
- **Rose:** `#ecbdbb` - Numbers, constants
- **Pine:** `#317590` - Git additions
- **Foam:** `#9dd0d9` - Functions
- **Text:** `#e1dff4` - Primary text

### Loophole Light
A clean, modern light theme with a vibrant purple accent (#917baa) that provides excellent readability while maintaining visual appeal.

**Color Palette:**
- **Base:** `#faf3ec` - Warm off-white background
- **Surface:** `#fef9f2` - Editor background
- **Overlay:** `#f3eadf` - Widget backgrounds
- **Iris:** `#917baa` - Primary accent (focus, highlights)
- **Love:** `#b5647b` - Keywords, errors
- **Gold:** `#eb9e35` - Strings
- **Rose:** `#d8837f` - Numbers, constants
- **Pine:** `#296a84` - Git additions
- **Foam:** `#5795a0` - Functions
- **Text:** `#58537a` - Primary text

## Features

- **Consistent Design Language** - Both themes share the same design principles
- **Semantic Highlighting** - Enhanced syntax highlighting support
- **Git Integration** - Clear git decoration colors
- **Terminal Colors** - Carefully selected ANSI colors for terminal
- **Complete UI Coverage** - Every UI element thoughtfully colored

## Installation

These themes are built into Loophole IDE. To activate:

1. Open Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`)
2. Type "Color Theme"
3. Select either:
   - `Loophole Dark`
   - `Loophole Light`
